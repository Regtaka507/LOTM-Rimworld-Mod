# Lord of the Mysteries — RimWorld Mod

Non-Steam download of the **Lord of the Mysteries** mod for **RimWorld 1.6**.
Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3809971059

> ⚠️ Download **`LordOfTheMysteries-vX.X.X.zip`** from Releases, not "Source code" (that one only has this README).
> ⚠️ Descargá **`LordOfTheMysteries-vX.X.X.zip`** desde Releases, no "Source code" (ese solo tiene este README).

## Installation (English)
1. Download the latest `LordOfTheMysteries-vX.X.X.zip` from **[Releases](../../releases)**.
2. Unzip it into your `RimWorld/Mods/` folder, so you get `RimWorld/Mods/LordOfTheMysteries/`.
3. Install **Harmony** (required): download it from https://github.com/pardeike/HarmonyRimWorld/releases/latest and unzip it into `RimWorld/Mods/` too.
4. In the game, enable **Harmony** first and **Lord of the Mysteries** after it.

To update, delete the old `LordOfTheMysteries` folder and unzip the new version.

## Instalación (Español)
1. Descargá el último `LordOfTheMysteries-vX.X.X.zip` desde **[Releases](../../releases)**.
2. Descomprimilo dentro de la carpeta `RimWorld/Mods/`, para que quede `RimWorld/Mods/LordOfTheMysteries/`.
3. Instalá **Harmony** (obligatorio): bajalo de https://github.com/pardeike/HarmonyRimWorld/releases/latest y descomprimilo también en `RimWorld/Mods/`.
4. En el juego, activá **Harmony** primero y **Lord of the Mysteries** después.

Para actualizar, borrá la carpeta `LordOfTheMysteries` vieja y descomprimí la versión nueva.
